Act 06 // ManiSkill2

Beyond one robot.

One benchmark is not enough to prove that a method works. We extended the pipeline to ManiSkill2 — a second robotic simulation suite built on a different robot arm with different proportions and different physics.

ManiSkill2 uses the Kinova Gen3 Lite, a slimmer arm with six joints. If unlearning works on both robots, it is likely to work in general — not just on the one we spent the most time with.

This is ongoing work and results will be added as the project develops.

Key facts

  • Second benchmark: ManiSkill2
  • Second robot: Kinova Gen3 Lite (six joints)
  • Independent physics simulator: SAPIEN
  • Status: in progress

Act 07 // RoboDK

Ongoing work: validating on real hardware.

Everything we have shown so far lives inside a simulator. Before any of it can be trusted on a physical robot, the movements it produces need to be checked against the real machine's limits — where it can reach, where it might collide, and where it risks damaging itself.

We are building that verification layer in RoboDK, an industrial tool used for robot simulation and kinematic checking. This work is in progress and will not complete within the current project window. It represents the natural next step for a policy that has already passed simulation testing.

Key facts

  • Independent verification of every learned motion
  • Collision and reach checking
  • Status: in progress
